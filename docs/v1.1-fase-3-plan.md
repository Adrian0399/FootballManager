## Notas importantes

- **No borrar los mocks** todavía. Los mocks sirven de fallback si el backend no responde, y se usan para los hooks P2 (operaciones) que aún no están conectados.
- **Mover las funciones puras** (`standings.ts`, `roundRobin.ts`, `playerStats.ts`) del frontend al backend. Se usan server-side para los servicios de agregación. El frontend deja de necesitarlas.
- **El seed** corre una sola vez (`pnpm db:seed`). El backend ya tiene los datos — solo falta el wire.
- **Auth**: el `apiClient` ya inyecta el Bearer token automáticamente. Todos los endpoints requieren `authenticate` middleware.
